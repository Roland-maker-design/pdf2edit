首个可用版本。

## 下载

`pdf2edit.exe`（约 89 MB）。Windows 10 / 11（64 位）双击即用——不用装 Python，不用命令行，不联网。

首次启动要把依赖解压到临时目录，可能白屏 3–8 秒，属正常，别重复双击。

## 能做什么

- **五路输出**：Markdown / Word / HTML / PowerPoint / Excel
- **三种入口**：桌面窗口、本地网页（只监听 127.0.0.1）、命令行
- **批量**：拖一个文件夹进来，逐份转换；一份失败不拖累其他；不同目录里的同名文件自动区分
- **该拒绝就拒绝**：文字层不可信（扫描件、坏 OCR）会明确说明原因并拒绝，不硬转出一堆乱码

## 验证情况

- 62 个自动化测试
- 165 组压测样本 × 5 种格式，0 个崩溃
- 真实 arXiv 论文（attention / BERT）标题层级正确
- exe 自检：真实 Word 导出样本转 4 种格式全部通过

## 已知限制（用前请看）

图片一律丢失；公式不转 LaTeX；合并单元格不支持；单元格内换行会让表格散架（输出里留 ⚠️ 标记）；旋转 90° 的文字顺序可能错乱；批量只扫一层文件夹、不递归；三栏以上排版未充分验证。

详见 README 的「已知限制」。
