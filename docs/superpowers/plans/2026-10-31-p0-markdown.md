# P0 Markdown 主线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让一份干净的电子版 PDF 吐出结构正确的 Markdown（标题/段落/列表），不可信的文字层被明确拒绝。

**Architecture:** PyMuPDF 的 text dict → 行聚类 → 结构重建 → IR → Markdown writer。质量闸门在解析前拦截，依据是字体是否带 ToUnicode 码表，而不是猜输出。

**Tech Stack:** Python 3.10、PyMuPDF 1.28、fontTools、pytest

**Spec:** `docs/specs/2026-10-31-design.md`

## Global Constraints

- 只处理电子版 PDF；扫描件、伪电子版、图片型一律拒绝，不硬转
- 输出必须是可编辑的语义结构，禁止绝对定位/文本框方案
- 中文段落合并时不得插入空格；英文之间必须有空格
- 表格识别属于 P1，本计划不实现

## Review Focus

- 中文行合并时被塞入多余空格
- 页眉/页码混进正文
- 表格被当成普通段落（P0 已知限制，需在输出层面标注）
- 字号相同的正文被误判成标题
- 整份文档只有一页时，页脚判定误删正文
